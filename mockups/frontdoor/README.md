# Crucible front door - three directions (2026-07-28)

Ungated landing mockups for play.burncoin.tech. Standalone HTML, nothing wired to the
live site. Sample data is a realistic mid-cycle state: $12.40 chest, Ronke Warden day.

Each must answer four things in ten seconds, with no reading:
the live pot in USD, today's Warden plus which community is buffed, what a swing costs
against what it pays, and one button.

| | Direction | Language |
|---|---|---|
| A | `a-odometer.html` | Arcade cabinet. Pot as a full-bleed odometer. |
| B | `b-fightbill.html` | Fight poster on bone stock. Warden as the headliner. |
| C | `c-loot.html` | The loot itself is the hero. Chest contents itemised on arrival. |

Screenshots in `shots/`, mobile (390x844) and desktop (1280x800), viewport-only,
which is the honest arrival test.

Dials: DESIGN_VARIANCE 9, MOTION_INTENSITY 8, VISUAL_DENSITY 2.
Variance is pushed high deliberately: these are meant to be structurally different,
not recolours of the existing dark-card grid.
